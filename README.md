# NegahJavan

نسخه تمیز و مستقل «نگاه جوان» برای Cloudflare Workers.

## معماری
- Cloudflare Worker: رابط عمومی، API و پنل تحریریه
- Cloudflare D1: خبرها و دسته‌بندی‌ها
- عکس و فیلم در فضای مستقل ابرآروان؛ بدون R2. کلیدهای آروان به‌صورت رمزگذاری‌شده در D1 نگهداری می‌شوند.
- Workers AI با binding نام `AI` برای پیشنهاد متن و تصویرسازی در تحریریه
- Secrets فقط در Cloudflare: `ADMIN_PASSWORD` و `AUTH_SECRET`

## مسیرها
- `/` صفحه اصلی
- `/editorial` پنل تحریریه
- `/api/health` وضعیت Worker / D1 / Auth
- `/category/:slug` دسته خبر
- `/news/:slug` صفحه خبر
- `/latest?page=2` آرشیو صفحه‌بندی‌شده
- `/sitemap.xml` نقشهٔ خبرهای منتشرشده و دسته‌ها
- `/feed.xml` خوراک RSS تازه‌ترین خبرها

## راه‌اندازی Cloudflare
1. ریپو را به Cloudflare Workers متصل و Worker را با نام `negahjavan` Deploy کنید.
2. از D1 موجود `negahjavan1-db` با شناسهٔ درج‌شده در `wrangler.jsonc` استفاده کنید.
3. فایل تنظیمات binding نام `DB`، هوش مصنوعی و دو دامنهٔ موجود `negahjavan.ir` و `www.negahjavan.ir` را حفظ می‌کند.
4. در Settings > Variables and Secrets دو Secret بسازید: `ADMIN_PASSWORD` و `AUTH_SECRET`.
5. Worker جداول را در اولین درخواست به‌صورت خودکار می‌سازد؛ اجرای دستی schema لازم نیست.

برای `AUTH_SECRET` از یک رشته تصادفی طولانی (حداقل 32 بایت) استفاده کنید.

## تحریریه و رسانه

- پیش‌نمایش تحریریه از همان کاور PNG سایت استفاده می‌کند. عکس‌های JPG و PNG در مرورگر تا ضلع بزرگ ۱۹۲۰ پیکسل آماده می‌شوند؛ برش مرکزی ۱۶:۹ اختیاری است. GIF و WebP با فرمت اصلی حفظ می‌شوند.
- سقف آپلود عکس ۸ مگابایت و ویدئو ۵۰ مگابایت است. انتخاب فایل، بارگذاری و ذخیرهٔ خبر سه مرحلهٔ جدا هستند؛ فایلِ خبر منتشرنشده عمومی نمی‌شود.
- اصلاح هوشمند متن با مدل Qwen فقط پیشنهاد می‌دهد. برای ثبت پیشنهاد باید آن را بررسی، اعمال و خبر را ذخیره کنید. نام، نقل‌قول و جزئیات همچنان نیاز به بررسی تحریریه دارند.
- ساخت تصویر برای خبر بی‌عکس با Flux انجام و در آروان ذخیره می‌شود. تصویر برچسب «تصویرسازی هوش مصنوعی» دارد؛ کاور گرافیکی بدون درخواست مدل همچنان در دسترس است.
- هوش مصنوعی روی ذخیره یا بازدید عمومی خودکار اجرا نمی‌شود. سقف داخلی روزانه ۴۰ واحد به وقت تهران است؛ پیشنهاد متن ۱ و تصویرسازی ۲ واحد. خطای مدل یا سهمیهٔ Cloudflare متن اصلی را حفظ می‌کند. سهمیه و هزینهٔ حساب Cloudflare مستقل از این سقف هستند؛ این پروژه پلن حساب را تغییر نمی‌دهد.
- نسخهٔ MP4 سبک و WebM را می‌توان به ویدئوی بارگذاری‌شده متصل کرد؛ تبدیل خودکار ویدئو انجام نمی‌شود.
